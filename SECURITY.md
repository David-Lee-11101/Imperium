# Security Policy

## Supported versions

Imperium does not currently publish a stable release line or support window. Security fixes are evaluated against the default branch.

## Reporting a vulnerability

Report suspected vulnerabilities privately to the repository owner. Do not open a public issue containing credentials, personal data, exploit details, or other sensitive material.

Include the affected revision, reproduction conditions, impact, and suggested mitigation when available. Sanitize logs and screenshots before sharing them. The owner will communicate triage and next steps through the same private channel; no response-time commitment is currently published.

For configuration guidance and trust boundaries, see [docs/SECURITY.md](docs/SECURITY.md).
